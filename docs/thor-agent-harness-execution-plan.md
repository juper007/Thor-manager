## 상태 표기

- `[ ]` 시작 전
- `[~]` 진행 중 — Markdown 자체 체크박스는 아니므로 진행 중인 작업에만 사용
- `[x]` 완료 및 검증됨
- `BLOCKED` 외부 승인이나 선행 작업이 필요한 상태

체크 항목은 구현만 끝났다고 완료 처리하지 않는다. 관련 테스트와 실제 Jetson Thor 검증까지 통과해야 `[x]`로 변경한다.

## 작업 갱신 규칙

매 작업이 끝날 때 이 문서를 함께 갱신한다.

1. 완료된 항목을 `[x]`로 변경한다.
2. 현재 작업 하나만 `[~]`로 표시한다.
