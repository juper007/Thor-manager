## 작업 갱신 규칙

매 작업이 끝날 때 이 문서를 함께 갱신한다.

1. 완료된 항목을 `[x]`로 변경한다.
2. 현재 작업 하나만 `[~]`로 표시한다.
3. 막힌 작업에는 `BLOCKED`와 이유를 기록한다.

5. 검증 없이 구현만 된 항목은 완료 처리하지 않는다.
